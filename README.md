## Minishell – 42 School Project

**Minishell** is one of the key projects at **42 School**, designed to provide an in-depth understanding of **Unix systems, command-line interpreters (shells), and process management**. The goal of the project is to create a **miniature version of Bash**, capable of executing basic command-line functions.

### Main Objectives of the Project

- **Developing a custom command-line interpreter** – Implementing a **simplified shell** that can process and execute commands.
- **Handling user input** – Parsing commands, arguments, and operators such as `|`, `<`, `>`, `>>`, and `;`.
- **Process and thread management** – Using **fork(), execve(), waitpid()** to create and control child processes.
- **Implementing pipes and I/O redirection** – Supporting `|`, `<`, `>`, and `>>` for command chaining.
- **Handling signals** – Properly responding to `Ctrl+C`, `Ctrl+D`, `Ctrl+\`, process interruptions, and background jobs.
- **Managing environment variables** – Supporting `env`, `export`, `unset`, and handling `$?` for status tracking.

### Key Learning Outcomes

- Deep understanding of **Unix system calls** and process management.
- Practical experience with **threads, pipes, and signals**.
- Strong skills in **parsing and string manipulation**.
- Developing **secure and stable code** with proper error handling.

The **Minishell** project is a crucial milestone in 42 School's curriculum as it provides real-world experience in **systems programming, concurrency, and inter-process communication**, essential for understanding **low-level programming and operating system functionality**.
